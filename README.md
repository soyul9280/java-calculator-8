# ✅ 기능 구현 목록

## 입력 초기화

- [x] 덧셈할 문자열 입력 안내 문자 출력
- [x] 입력 초기화

## 덧셈 진행

### 문자열 분석

### 커스텀 구분자 사용

- [x] 커스텀 구분자 인식
- [x] `예외상황`: 커스텀 구분자 인식 시작 문자열 외 다른 문자열로 시작
- [x] `예외상황`: 커스텀 구분자가 숫자인 경우
- [x] `예외상황`: 커스텀 구분자가 문자열로 이뤄져있는 경우
- [x] `예외상황`: 커스텀 구분자 인식 끝 문자열 잘못된 경우

### 기본 구분자 사용

- [x] 기본 구분자 인식
- [x] `예외상황`: 커스텀 구분자 선언하지 않고 기본 구분자 외 구분자 사용

### 계산

- [x] 구분자를 기준으로 숫자 추출
    - [x] `예외상황`: 양의 정수가 아닌 경우
    - [x] `예외상황`: 구분자만 있고 숫자가 없는 경우
    - [x] `예외상황`: 구분자가 없고 숫자만 있는 경우
    - [x] `예외상황`: 중간에 공백문자 있는 경우
    - [x] `예외상황`: 문자열 길이가 3미만인 경우

- [x] 인식한 숫자들로 계산
    - [x] 빈 값이면 0 반환

## 결과 출력 및 종료

- [x] 결과 메시지 출력

## 🤼 클래스들의 역할

- model
    - Calculator

    1. 계산기 역할
    2. 구분자와 숫자에 대한 상태 변경
    3. 계산 결과 반환
- view
    - InputView: 사용자 입력 받기
    - OutputView: 화면에 결과 출력
- controller
    - Validator: 입력된 문자열 검증
    - CustomSeparatorService: 커스텀 구분자 추출
    - CalculatorController: 중계자 역할로 계산기 초기화 및 데이터 전달
