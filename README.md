# ✅ 기능 구현 목록

## 입력 초기화

- [x] 덧셈할 문자열 입력 안내 문자 출력
- [x] 입력 초기화

## 덧셈 진행

### 문자열 분석

### 커스텀 구분자 사용

- [x] 커스텀 구분자 인식
- [x] 예외상황: 커스텀 구분자 인식 시작 문자열 외 다른 문자열로 시작
- [ ] 예외상황: 커스텀 구분자가 숫자인 경우
- [x] 예외상황: 커스텀 구분자가 문자열로 이뤄져있는 경우
- [x] 예외상황: 커스텀 구분자 인식 끝 문자열 잘못된 경우

### 기본 구분자 사용

- [x] 기본 구분자 인식
- [ ] 예외상황: 커스텀 구분자 선언하지 않고 기본 구분자 외 구분자 사용

### 계산

- [x] 구분자를 기준으로 숫자 추출
    - [x] 예외상황: 양의 정수가 아닌 경우
    - [ ] 예외상황: 구분자만 있고 숫자가 없는 경우
    - [ ] 예외상황: 구분자가 없고 숫자 1개만 있는 경우
- [x] 인식한 숫자들로 계산
